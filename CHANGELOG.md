# Changelog

## 1.3.0 — 2026-10-08
- Signed-in header shows only your profile and KR (Junk, ranked points and Wallet hidden).
- Class and Customize buttons moved to the left middle of the menu; the "Now Playing" stat line moved to
  the bottom edge.
- Fix: Krunker's Frame Cap setting now gives the chosen FPS (a 400 cap used to drop to about 60 FPS).

## 1.2.0 — 2026-10-08
- Cleaner signed-in menu: hides Battle Pass, Daily Spin, What's New, Turf Wars, Leaderboards and the
  Guide entry plus leftover dividers (Market & Trading stays).
- Vibe Client branding: "ViBE CLIENT" banner replacing the Krunker logo on the menu (with a small version
  tag), pink→amber Quick Match and play-button hover glow, logo on Krunker's loading screen, window
  title "Krunker Vibe Client".

## 1.1.0 — 2026-10-08
- Cleaner main menu: hides the store bundle promo, Live Streams panel, "Get Signup Rewards" and
  "Register now" nags, the web-push "Notifications" button (can't work in a desktop client), the
  oversized Guide entry, "Popular Now" and the footer links.
- Compact play buttons: Quick Match and Ranked full width, Host / Find / Custom Games in one row.
- Internal: Discord Rich Presence client added but disabled (no Discord application id yet).

## 1.0.0 — 2026-10-08
- First release: Electron 44 client for krunker.io.
- Unlimited FPS, raw mouse input (fixes flicks on fast mouse movement).
- Keybinds: F5 reload, F6 new game, F11 fullscreen, F12 DevTools; no default menu shortcuts (Ctrl+W).
- krunker.io links open in client windows, other links in the default browser.
- Built-in ad blocker; hides the empty ad frames.
- Identifies as plain Chrome so Krunker doesn't show its "discontinued client" popup.
- Original logo and splash screen; Windows installer.
